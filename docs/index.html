01 / SOURCE

Official UCI data

The file has 48,204 rows from October 2012 to September 2018 at a single westbound I-94 station.

02 / CLEANING

One count per hour

7,629 additional rows repeat timestamps for alternate weather descriptions. Their traffic counts agree, so each hour is counted once.

03 / LIMITS

Patterns, not causes

Missing hours, holidays, uneven coverage, and overlapping weather labels affect comparisons. This page makes no causal weather claim.
